# Project skills

Skills in this directory are discovered at project scope — each
subdirectory holds a `SKILL.md` plus any supporting files it references.

## Vendored skills

### `rust-skills/`

Vendored from <https://github.com/leonardomso/rust-skills> at revision
`fd2a861ab0406a4ac536a55274d14ea6fd1ca9c9` (v1.5.1), licensed MIT —
see `rust-skills/LICENSE`. Only `SKILL.md`, `rules/`, and `LICENSE` are
carried; the upstream `AGENTS.md`/`CLAUDE.md` are byte-identical copies
of `SKILL.md` for other tools and are omitted. To update, re-copy those
paths from a newer upstream revision and bump `vendored-revision` in the
`SKILL.md` frontmatter.
