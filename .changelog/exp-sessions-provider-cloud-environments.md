- Tasks can now run in the provider's own hosted environment — the composer's Environment menu gains a named cloud row (Devin Cloud, Codex Cloud, Claude Cloud, Cursor Cloud, Copilot Cloud, Droid Cloud) for providers that support one. Cloud tasks run against the repo's pushed state only, so Goddard asks you to push an unpushed branch or commits before submitting, and the task runs and reports like any other session.
