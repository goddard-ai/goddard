- The boss can publish files and folders its employees produce as bundles with `goddard-agent boss publishBundle`; bundles appear in a Recent bundles section above Pinned for twelve hours. Clicking one opens its task — the boss chat with the bundle attached as context — and a previewable file also opens in the in-app file viewer. Bundle rows can be pinned, moved to dormant, archived, revealed in Finder, or removed from the sidebar through their hover buttons and right-click menu.
