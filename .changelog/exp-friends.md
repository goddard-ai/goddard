- Add project sharing between friends: pick which projects a friend can see, and when their share matches one of your repos by `origin` remote you can opt in to automatic sync — the default branch syncs out of the box, other branches are per-branch toggles, and commits you land auto-push (toggleable). A friend's push syncs immediately; a rebase conflict or dirty checkout raises an alert offering resolve-in-chat, merge instead, or abort — aborting pauses that branch until you sync it manually.
- Attach an optional message when sending a file or folder to a friend — the receiver's chat shows the note above the delivered file as an agent-style message
- Opt in to session sharing per shared project: a "Share sessions" toggle under each outgoing share lets a friend list that project's sessions and peek into any of them — live and read-only. Watched sessions show a banner naming the friend, never touch the friend's runtime, and disappear from view the moment sharing is revoked.
