- The boss can open dedicated planning sessions through a new `createPlan` operation: each session works like a product designer — thinking through the user experience, flows, edge cases, and tradeoffs — and drafts a design doc under `memory/plans/` in the boss's files, leaving implementation specifics to the employees who build it. Planning sessions run Codex's GPT-6.1-Sol model at medium effort by default. Pending employee reports no longer block chat history when opening a boss, employee, or existing task from the sidebar.
