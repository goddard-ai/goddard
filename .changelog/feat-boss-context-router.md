- The Boss now keeps a live map of your projects, tasks, employees, and automations: every message you send it carries a compact overview of what is live in each project, and it can fetch the full snapshot itself with the new `context` operation. With an evaluation backend configured, a context router also attaches that full snapshot automatically to messages that need it, tracking which project holds your attention across the chat. When a routed message had a project in focus, that project shows in the sent message's hover footer beside the timestamp.
