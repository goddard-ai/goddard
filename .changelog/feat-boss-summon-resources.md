- Boss summons can now declare the host resources an employee needs up front — `resources: {"native_builds": 1}` for a device build, named `ios:`/`android:` devices with `resident_devices`, or `desktop_input` — and a contested set queues the ticket instead of erroring, so jobs that need a simulator or a build slot can be staffed in one step. The new `setResources` control changes the set on an employee that is already summoned: a queued ticket re-enters admission on it, and a running employee swaps to it once capacity frees without interrupting its turn.
